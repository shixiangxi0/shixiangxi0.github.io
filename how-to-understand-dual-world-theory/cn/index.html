如何理解双世界理论

前置阅读：双世界理论：游戏架构的另一种视角

双世界不仅仅只是逻辑和表现的重新划分。更为本质的是，它在重新定义一个"对象"在这个世界上到底"拥有什么"。

传统游戏对象通常是：对象 = 数据 + 行为 + 表现

于是一个 Enemy：

  • 有 hp
  • 有 AI
  • 有动画
  • 有特效
  • 有移动
  • 有受击
  • 有状态机

最后变成一个自包含宇宙。

双世界理论认为：对象不拥有世界事实。 对象只拥有行为能力、表现能力。世界事实不能属于对象，世界事实属于逻辑层。

这是架构层面就带来的一种去中心化。

例如：角色并不"拥有"自己的血量。 真正的血量存在于逻辑层状态树、事件时间线（event timeline）、权威状态（authoritative state）。角色对象只是读取、表现、对变化做反应。

这会让很多东西突然变得极其清晰。

比如"死亡动画"为什么总容易写乱？

传统思维：

Enemy.dead = true
Enemy.playDeath()
Enemy.disableCollision()
Enemy.remove()

死亡既是状态、又是动画、又是生命周期、又是场景管理——全缠一起。

双世界理论里：

logic:
    hp <= 0
    emit die

presentation:
    收到 die
    播放死亡演出

scene:
    收到 remove_entity
    清理实体

因果链是完整的，显式的。

传统游戏开发很多时候并不注重因果。例如：

Buff 修改 AttackSpeed
AttackSpeed 影响 Animator
Animator 改变 HitTiming
HitTiming 提前导致 ComboWindow 改变

最后没人知道："到底是谁导致了什么？"

而双世界中天然会逼迫开发者：

cause → event → state transition → projection

因果必须显式化。这是它非常强的地方。因为可维护性的本质其实是因果透明，或者说，可验证，可追溯。

双世界理论天然在削弱传统OOP的"对象状态机中心主义"，即对象不拥有世界事实，对象不能持有裁决权。

传统游戏开发很容易：

Idle → Run → Attack → Hit → Dead

然后每个对象一个巨大 FSM。在双世界中会逐渐把状态、行为、时间窗口、表现过程拆成不同层级。最后对象本身会越来越"薄"。真正变厚的是事件流、契约、临时窗口、行为组合。

而"组件自治"在这里也不是普通 ECS 那种自治。普通 ECS 的自治还是每帧 update 自己。双世界中的组件自治更像有限授权自治：

组件可以自由连续运行，但不能篡改世界事实。整个过程最终必须收敛为可共享、可裁决、可回放的世界事实。

这是非常高级的约束。它更像 UI 的乐观渲染（optimistic rendering）、分布式系统里的最终一致性（eventual consistency）。

这套体系还有个隐藏优势：它天然适合多人协作。因为：

  • 美术/动画只管"怎么演"
  • 系统策划只管"事实怎么变化"
  • 客户端只管"如何投影"
  • 服务端只管"因果是否成立"

边界会异常清晰。很多大型项目后期崩掉，其实就是："所有人都在偷偷改世界事实。"

还有一些值得提到的东西——宏观世界，永远没有真正意义上的并行。你可以把它理解成：

宏观世界的本质不是"同时发生"，而是"因果关系最终可排序"。

这很关键。因为我们感知中的"同时"——两个人同时挥剑、两颗子弹同时命中、两个线程同时运行——本质上都只是局部观察下无法分辨先后。但只要世界需要给出结果、状态需要收敛、事实需要成立，系统最终一定会选择一个因果顺序。否则世界无法稳定。

这其实就是裁决为什么不可避免。

比如游戏里的"同时攻击"：两个角色同时砍死对方。看起来：

A hit B
B hit A

同时发生。但逻辑层一定要回答：谁先死亡？死亡后技能还能不能触发？吸血是否成立？死亡爆炸是否发生？仇恨归属怎么算？

于是系统必须排序。哪怕玩家感觉是同时、动画也是同时、特效也是同时——事实层仍然必须裁决。

数据库事务：两个用户同时修改余额。物理世界里 CPU 并行、网络并行、请求并行，但数据库最后一定 序列化（serialize）。否则钱会凭空消失、状态腐化、世界失真。

所以 ACID 本质上就是："世界事实必须可排序"。

法律系统：两个人互相指控。现实里事件可能同时发生，但法院最后一定形成一条可叙述的因果链。因为社会秩序和媒体大众都需要"事实版本"。这也是一种 authority、adjudication、serialization。

宏观世界这个词非常重要。因为微观层面，可能确实存在
量子叠加、
概率态、
真并发、
非决定性。
但一旦进入宏观层面，世界就必须收敛成可叙述现实。

因为宏观系统需要稳定因果。

否则：

无法记忆
无法推理
无法协作
无法预测
无法治理

换句话说：文明本身就是建立在因果关系最终可排序之上的。
